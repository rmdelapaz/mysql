🗄️ MySQL Foundations: Master the World's Most Popular Database

Learn MySQL from scratch. By the end of this course, you'll be creating databases, writing powerful queries, designing table relationships, and managing data like a pro.

📚 About This Course

This course teaches you MySQL, one of the most widely used open-source relational databases, from the ground up. No prior database experience required. You'll start by understanding what databases are and why they matter, install MySQL on your own machine, and progressively learn everything from simple queries to multi-table joins, database design, transactions, and security.

Every lesson builds on the last with hands-on exercises using real data. By Module 4 you'll be writing complex multi-table queries, and by the end you'll understand how to design, optimize, secure, and back up production-quality databases. This course is the first step in a learning path that continues with PHP Foundations and PHP & WordPress.

What You'll Learn

  • How relational databases work — tables, rows, columns, and SQL
  • How to create databases, define tables, and enforce data integrity with constraints
  • How to write queries — filtering, sorting, aggregating, and joining data across tables
  • How to design normalized database schemas with proper relationships
  • How to write modern queries with CTEs, recursive queries, and window functions
  • How to use indexes, views, stored procedures, transactions, and JSON columns
  • How to manage users, permissions, backups, and imports/exports
  • How to design and build a complete database of your own in a final project

Who This Course Is For

  • Complete beginners with no database experience
  • Web developers who want to understand the data layer
  • Students preparing for PHP, Python, or JavaScript backend development
  • Anyone who works with data and wants to learn SQL

Learning Path

This course is the first in a three-course sequence:

  1. MySQL Foundations (this course) — Database fundamentals and SQL
  2. PHP Foundations — Core PHP language + PDO database integration
  3. PHP & WordPress — Building dynamic sites with WordPress

Taking or teaching it in a classroom? The instructor-led syllabus lays the course out as 14 three-hour sessions in two parts; Part 1 (Modules 1 to 4, 7 sessions) can also run on its own.

📖 Course Modules

Eight modules, 25 lessons. From Lesson 2.1 on, the course is built around one bookstore database; from Lesson 4.2 on, every lesson starts by reloading it from bookstore.sql, and the final project builds a database of your own.

Module 1: Getting Started 4 h 10 min

Meet relational databases, install MySQL 9.7 LTS, and run your first statements in the mysql client and phpMyAdmin.

  • Lesson 1.1: What Is a Database? 75 min
  • Lesson 1.2: Installing MySQL 90 min
  • Lesson 1.3: MySQL CLI & phpMyAdmin 85 min

Module 2: Tables & Data Types 4 h 50 min

Create the bookstore database, choose data types and constraints, and add, read, change and delete rows.

  • Lesson 2.1: Creating Databases & Tables 85 min
  • Lesson 2.2: Data Types & Constraints 100 min
  • Lesson 2.3: CRUD Operations 105 min

Module 3: Querying Data 6 h 10 min

Filter, sort, summarize and nest queries to get exactly the rows and numbers you need.

  • Lesson 3.1: WHERE Clauses, Operators & Filtering 95 min
  • Lesson 3.2: Sorting & Limiting Results 85 min
  • Lesson 3.3: Aggregate Functions & GROUP BY 90 min
  • Lesson 3.4: Subqueries & Nested Queries 100 min

Module 4: Relationships & Joins 5 h 15 min

Split data into related tables, protect it with foreign keys, and combine it again with joins.

  • Lesson 4.1: Table Relationships 105 min
  • Lesson 4.2: Foreign Keys & Referential Integrity 100 min
  • Lesson 4.3: Joins 110 min

Module 5: Modern Queries 3 h 20 min

Write readable multi-step queries with CTEs, walk hierarchies recursively, and rank and total rows with window functions.

  • Lesson 5.1: CTEs & Recursive Queries 100 min
  • Lesson 5.2: Window Functions 100 min

Module 6: Database Design 5 h 05 min

Speed up queries with indexes, package queries as views, and design normalized schemas.

  • Lesson 6.1: Indexes & Query Optimization 105 min
  • Lesson 6.2: Views 95 min
  • Lesson 6.3: Database Design & Normalization 105 min

Module 7: Advanced Features 7 h

Reusable logic in stored procedures and functions, all-or-nothing changes with transactions, flexible JSON columns, and secure user accounts.

  • Lesson 7.1: Stored Procedures & Functions 105 min
  • Lesson 7.2: Transactions 110 min
  • Lesson 7.3: JSON Columns 100 min
  • Lesson 7.4: User Management & Permissions 105 min

Module 8: Real-World Skills 7 h 05 min

Move data in and out, design and build a database of your own from scratch, and plan your next steps.

  • Lesson 8.1: Importing & Exporting Data 105 min
  • Lesson 8.2: Final Project: Design and Build a Database 240 min
  • Lesson 8.3: Next Steps & Best Practices 80 min

✅ Prerequisites

This course is designed for absolute beginners. You need:

  • A computer running Windows, macOS, or Linux
  • Basic comfort with the command line (typing commands and pressing Enter)
  • No prior database or SQL experience required

Required Software (installed during the course)

  • MySQL 9.7 LTS: the database server and the mysql client (Lesson 1.2 covers Windows, macOS, Linux and Docker). MySQL 8.4 LTS works for almost everything; lessons point out the few differences
  • phpMyAdmin (optional): a browser-based tool for the same database (Lesson 1.3)
  • A text editor: VS Code recommended for writing .sql files

Using XAMPP or a shared web host? They usually run MariaDB, a close relative of MySQL. Nearly all of the course works there, and lessons flag the places where MariaDB behaves differently.
