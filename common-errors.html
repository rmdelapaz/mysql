❌ Common MySQL Errors

The errors you are most likely to meet in this course, each with the exact message MySQL 9.7 prints, a statement that triggers it, and the fix. When you hit an error, search this page for its number (Ctrl+F, or Cmd+F on a Mac).

💡 How to read an error

ERROR 1452 (23000): Cannot add or update a child row: ... has three parts: the MySQL error number (1452, the one to search for), the SQLSTATE code (23000, a standard class shared by many databases; 23 means an integrity constraint), and the message. In a syntax error, the text after near is where MySQL stopped understanding you: the mistake is right there or just before it.

💡 Every example here is real

Each "Try it" statement was run on MySQL 9.7 against the course's bookstore.sql, in page order, and the error card shows what the server actually printed. The page starts with no database selected (that is how the first two errors happen) and loads bookstore.sql in the third entry.

🗄️ Database & Table Errors

Background: Lesson 1.3: MySQL CLI & phpMyAdmin and Lesson 2.1: Creating Databases & Tables.

ERROR 1046: No database selected

Try it (right after logging in, before any USE):

SELECT title FROM books;

Error

ERROR 1046 (3D000): No database selected

Why: a table name alone means "the table in the current database", and there is none yet. Fix: USE bookstore; first, write bookstore.books, or log in with mysql -u root -p bookstore.

ERROR 1049: Unknown database

USE bookstor;

Error

ERROR 1049 (42000): Unknown database 'bookstor'

Why: a typo, or the database was never created (or was dropped). Fix: SHOW DATABASES; to see the real names. For the course database, load (or reload) the script, which creates bookstore and selects it:

SHOW DATABASES;
SOURCE bookstore.sql;
SELECT DATABASE();

ERROR 1007: Can't create database; database exists

CREATE DATABASE bookstore;

Error

ERROR 1007 (HY000): Can't create database 'bookstore'; database exists

Fix: CREATE DATABASE IF NOT EXISTS bookstore; turns the error into a note. To start over on purpose, DROP DATABASE first (it deletes every table in it).

ERROR 1050: Table already exists

CREATE TABLE authors (
    id   INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL
);

Error

ERROR 1050 (42S01): Table 'authors' already exists

Fix: CREATE TABLE IF NOT EXISTS skips the statement when the table exists, but it does not change the existing table to match: use ALTER TABLE for that. Dropping and re-creating the table deletes its rows.

ERROR 1146: Table doesn't exist

SELECT * FROM book;

Error

ERROR 1146 (42S02): Table 'bookstore.book' doesn't exist

Common causes: a typo (book for books), the wrong database selected, a table that was never created, or letter case: on Linux, table names are case-sensitive (Books is not books); on Windows and macOS they are not. Fix: check where you are and what exists:

SELECT DATABASE();
SHOW TABLES;

ERROR 1051: Unknown table

DROP TABLE reviews;

Error

ERROR 1051 (42S02): Unknown table 'bookstore.reviews'

Fix: DROP TABLE IF EXISTS reviews; in scripts that may run more than once.

ERROR 1060: Duplicate column name

ALTER TABLE books ADD COLUMN price DECIMAL(8, 2);

Error

ERROR 1060 (42S21): Duplicate column name 'price'

Fix: the column is already there. DESCRIBE books; shows it; use ALTER TABLE ... MODIFY COLUMN to change its type.

ERROR 1091: Can't DROP; check that column/key exists

ALTER TABLE books DROP COLUMN isbn;

Error

ERROR 1091 (42000): Can't DROP 'isbn'; check that column/key exists

Fix: check the real column, index or constraint name with SHOW CREATE TABLE books\G. Foreign keys are dropped by their constraint name (DROP FOREIGN KEY fk_books_author), not by the column name.

✍️ Syntax & Query Errors

Background: Module 3, from Lesson 3.1: WHERE Clauses, Operators & Filtering to Lesson 3.4: Subqueries & Nested Queries, and Module 5 (Lesson 5.1: CTEs & Recursive Queries, Lesson 5.2: Window Functions).

ERROR 1064: You have an error in your SQL syntax

Try it: a typo in a keyword, and a reserved word used as an alias.

SELECT title, price FORM books;
SELECT title, price AS rank FROM books;

Error

ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'books' at line 1
ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'rank FROM books' at line 1

Read the "near" part: in the first error MySQL read FORM as an alias for price and then choked on books; in the second, rank is a keyword (since MySQL 8.0 it names the RANK() window function). Common causes: misspelled keywords, a missing comma or parenthesis, unbalanced quotes, a reserved word (order, rank, window, groups) as a name, or a shell command such as mysqldump typed at the mysql> prompt. Fix:

SELECT title, price FROM books ORDER BY price DESC LIMIT 3;
SELECT title, price AS rank_num FROM books ORDER BY price DESC LIMIT 3;   -- or `rank` in backticks

⚠️ The missing comma that is NOT an error

Forget the comma between two column names and MySQL treats the second name as an alias for the first: no error, just a wrong result. Here the column called price holds titles:

SELECT title price FROM books WHERE id <= 3 ORDER BY id;

Output

+-----------------------+
| price                 |
+-----------------------+
| Dune                  |
| 1984                  |
| To Kill a Mockingbird |
+-----------------------+

ERROR 1054: Unknown column

Try it: using a SELECT alias in WHERE.

SELECT title, price * 0.9 AS sale_price
FROM books
WHERE sale_price < 8;

Error

ERROR 1054 (42S22): Unknown column 'sale_price' in 'where clause'

Why: WHERE is evaluated before SELECT, so the alias does not exist yet. Other causes: a typo, a column that is in a different table, or a missing table alias in a join. The message says where MySQL looked ('where clause', 'field list', 'on clause'...). Fix: repeat the expression (or wrap the query in a CTE or derived table). DESCRIBE books; lists the real column names.

SELECT title, price * 0.9 AS sale_price
FROM books
WHERE price * 0.9 < 8
ORDER BY sale_price;

Output

+---------------------+------------+
| title               | sale_price |
+---------------------+------------+
| Pride and Prejudice |      7.191 |
| Animal Farm         |      7.641 |
+---------------------+------------+

ERROR 1052: Column is ambiguous

SELECT id, title, name
FROM books
JOIN authors ON authors.id = books.author_id;

Error

ERROR 1052 (23000): Column 'id' in field list is ambiguous

Why: both tables have an id column. Fix: qualify it, ideally with short table aliases (Lesson 4.3: Joins):

SELECT b.id, b.title, a.name
FROM books b
JOIN authors a ON a.id = b.author_id
WHERE b.id <= 3
ORDER BY b.id;

ERROR 1055: Expression is not in GROUP BY clause

SELECT author_id, title, COUNT(*)
FROM books
GROUP BY author_id;

Error

ERROR 1055 (42000): Expression #2 of SELECT list is not in GROUP BY clause and contains nonaggregated column 'bookstore.books.title' which is not functionally dependent on columns in GROUP BY clause; this is incompatible with sql_mode=only_full_group_by

Why: an author with two books has two titles; which one belongs on the single result row? MySQL's default ONLY_FULL_GROUP_BY mode refuses to guess (Lesson 3.3: Aggregate Functions & GROUP BY). Fix: group by the column too, aggregate it, or drop it. Never "fix" this by removing ONLY_FULL_GROUP_BY from sql_mode: that only hides the question. (MariaDB has the mode off by default and silently returns one arbitrary title.)

SELECT author_id, GROUP_CONCAT(title ORDER BY title SEPARATOR ', ') AS titles, COUNT(*) AS books
FROM books
GROUP BY author_id
HAVING COUNT(*) > 1
ORDER BY author_id;

Output

+-----------+-------------------------------+-------+
| author_id | titles                        | books |
+-----------+-------------------------------+-------+
|         2 | 1984, Animal Farm             |     2 |
|         6 | Lord of the Rings, The Hobbit |     2 |
+-----------+-------------------------------+-------+

ERROR 1140: Aggregated query without GROUP BY

SELECT author_id, COUNT(*) FROM books;

Error

ERROR 1140 (42000): In aggregated query without GROUP BY, expression #1 of SELECT list contains nonaggregated column 'bookstore.books.author_id'; this is incompatible with sql_mode=only_full_group_by

Why: COUNT(*) collapses all rows into one, so a plain column has no single value. Fix: add GROUP BY author_id (one row per author), or remove author_id (one row in total).

ERROR 1111: Invalid use of group function

SELECT author_id
FROM books
WHERE COUNT(*) > 1
GROUP BY author_id;

Error

ERROR 1111 (HY000): Invalid use of group function

Why: WHERE filters single rows before any grouping, so there is nothing to count yet. Fix: filter groups with HAVING:

SELECT author_id, COUNT(*) AS books
FROM books
GROUP BY author_id
HAVING COUNT(*) > 1
ORDER BY author_id;

ERROR 1242: Subquery returns more than 1 row

SELECT title
FROM books
WHERE author_id = (SELECT id FROM authors WHERE birth_year < 1900);

Error

ERROR 1242 (21000): Subquery returns more than 1 row

Why: = needs exactly one value, and more than one author was born before 1900. Fix: use IN for a list (Lesson 3.4):

SELECT title
FROM books
WHERE author_id IN (SELECT id FROM authors WHERE birth_year < 1900)
ORDER BY title;

ERROR 1241: Operand should contain 1 column(s)

SELECT title
FROM books
WHERE author_id IN (SELECT id, name FROM authors WHERE name LIKE 'J%');

Error

ERROR 1241 (21000): Operand should contain 1 column(s)

Fix: a subquery compared with one column must return one column: SELECT id FROM authors ....

ERROR 1248: Every derived table must have its own alias

SELECT AVG(n)
FROM (SELECT COUNT(*) AS n FROM books GROUP BY author_id);

Error

ERROR 1248 (42000): Every derived table must have its own alias

Fix: name the subquery: ... GROUP BY author_id) AS per_author;. A CTE avoids the problem and reads better:

WITH per_author AS (
    SELECT author_id, COUNT(*) AS n FROM books GROUP BY author_id
)
SELECT AVG(n) AS avg_books_per_author FROM per_author;

Output

+----------------------+
| avg_books_per_author |
+----------------------+
|               1.2222 |
+----------------------+

ERROR 1093: You can't specify target table for update in FROM clause

DELETE FROM books
WHERE price = (SELECT MIN(price) FROM books);

Error

ERROR 1093 (HY000): You can't specify target table 'books' for update in FROM clause

Why: MySQL will not read a table in a subquery while it changes that same table. Fix: wrap the subquery in a derived table, which MySQL computes first. (The cheapest book, Pride and Prejudice, has been ordered, so its order lines go first; the demo runs inside a transaction and rolls back.)

START TRANSACTION;
DELETE FROM order_items
WHERE book_id IN (SELECT id FROM books WHERE price = (SELECT MIN(price) FROM books));
DELETE FROM books
WHERE price = (SELECT min_price FROM (SELECT MIN(price) AS min_price FROM books) AS tmp);
SELECT COUNT(*) AS books_left FROM books;
ROLLBACK;

ERROR 3593: You cannot use the window function in this context

SELECT title, price
FROM books
WHERE ROW_NUMBER() OVER (ORDER BY price DESC) <= 3;

Error

ERROR 3593 (HY000): You cannot use the window function 'row_number' in this context.'

Why: window functions are computed after WHERE, GROUP BY and HAVING. Fix: compute the number in a CTE, then filter it (Lesson 5.2: Window Functions):

WITH ranked AS (
    SELECT title, price, ROW_NUMBER() OVER (ORDER BY price DESC) AS row_num
    FROM books
)
SELECT title, price FROM ranked WHERE row_num <= 3 ORDER BY row_num;

Output

+-----------------------+-------+
| title                 | price |
+-----------------------+-------+
| Lord of the Rings     | 15.99 |
| Dune                  | 14.99 |
| To Kill a Mockingbird | 11.99 |
+-----------------------+-------+

ERROR 3636: Recursive query aborted

WITH RECURSIVE numbers AS (
    SELECT 1 AS n
    UNION ALL
    SELECT n + 1 FROM numbers
)
SELECT n FROM numbers;

Error

ERROR 3636 (HY000): Recursive query aborted after 1001 iterations. Try increasing @@cte_max_recursion_depth to a larger value.

Why: the recursive part has no condition that ever stops it. Fix: add the stop condition (Lesson 5.1: CTEs & Recursive Queries). Raise cte_max_recursion_depth only when a correct query really needs more than 1000 levels.

WITH RECURSIVE numbers AS (
    SELECT 1 AS n
    UNION ALL
    SELECT n + 1 FROM numbers WHERE n < 5
)
SELECT n FROM numbers;

🧱 Data & Constraint Errors

Background: Lesson 2.2: Data Types & Constraints, Lesson 2.3: CRUD Operations and Lesson 4.2: Foreign Keys & Referential Integrity. MySQL runs in strict mode by default, so bad values are rejected with an error instead of being quietly changed.

ERROR 1062: Duplicate entry for key

INSERT INTO customers (first_name, last_name, email, city)
VALUES ('Alice', 'Jones', 'alice@example.com', 'Boston');

Error

ERROR 1062 (23000): Duplicate entry 'alice@example.com' for key 'customers.email'

Why: customers.email is UNIQUE and Alice Johnson already has that address. The key is named table.index (here the unique index on email). Fix: look first, then decide: a different value, or an upsert that updates the existing row (MySQL's row-alias syntax; MariaDB uses VALUES(city) instead). INSERT IGNORE also exists, but it silently turns many other errors into warnings, so avoid it.

SELECT id, first_name, last_name, city FROM customers WHERE email = 'alice@example.com';

START TRANSACTION;
INSERT INTO customers (first_name, last_name, email, city)
VALUES ('Alice', 'Johnson', 'alice@example.com', 'Boston') AS new
ON DUPLICATE KEY UPDATE city = new.city;
SELECT id, first_name, city FROM customers WHERE email = 'alice@example.com';
ROLLBACK;

ERROR 1048: Column cannot be null

INSERT INTO books (title, author_id, price) VALUES ('Untitled Draft', 2, NULL);

Error

ERROR 1048 (23000): Column 'price' cannot be null

Fix: supply a real value. Only relax the column (MODIFY COLUMN ... NULL) if "unknown" is truly allowed by the design.

ERROR 1364: Field doesn't have a default value

INSERT INTO books (title, author_id) VALUES ('Untitled Draft', 2);

Error

ERROR 1364 (HY000): Field 'price' doesn't have a default value

Why: price is NOT NULL with no DEFAULT, and you left it out of the column list. Fix: include it, or give the column a default (ALTER TABLE books ALTER COLUMN price SET DEFAULT 0.00;) if a default makes sense.

ERROR 1406: Data too long for column

INSERT INTO categories (name) VALUES ('Science Fiction and Fantasy for Readers Aged Twelve and Up');

Error

ERROR 1406 (22001): Data too long for column 'name' at row 1

Why: categories.name is VARCHAR(50). Fix: shorten the value, or widen the column if longer values are legitimate: ALTER TABLE categories MODIFY COLUMN name VARCHAR(100) NOT NULL;

ERROR 1366: Incorrect integer value

INSERT INTO books (title, author_id, price, pages) VALUES ('Untitled Draft', 2, 9.99, 'about 300');

Error

ERROR 1366 (HY000): Incorrect integer value: 'about 300' for column 'pages' at row 1

Fix: the value must match the column type: 300, not 'about 300'. When importing a CSV, this usually means the columns are in a different order than you listed, or the header row was not skipped.

ERROR 1264: Out of range value

UPDATE books SET price = 1234567.89 WHERE id = 1;

Error

ERROR 1264 (22003): Out of range value for column 'price' at row 1

Why: DECIMAL(8, 2) holds at most 999999.99. Fix: check the value (a typo?), or widen the type.

ERROR 1292: Incorrect date value

INSERT INTO orders (customer_id, order_date) VALUES (1, '2026-02-30');

Error

ERROR 1292 (22007): Incorrect date value: '2026-02-30' for column 'order_date' at row 1

Why: February has no 30th, and dates must be written 'YYYY-MM-DD' ('02/28/2026' fails the same way). Fix: a real date in that format, or STR_TO_DATE('02/28/2026', '%m/%d/%Y') to convert other formats.

ERROR 1265: Data truncated for column

UPDATE employees SET department = 'marketing' WHERE id = 4;

Error

ERROR 1265 (01000): Data truncated for column 'department' at row 1

Why: department is an ENUM('sales', 'inventory', 'management', 'support'), and 'marketing' is not on the list. Fix: use an allowed value, or add the new one with ALTER TABLE employees MODIFY COLUMN department ENUM(...) listing all values.

ERROR 3819: Check constraint is violated

UPDATE employees SET salary = 0 WHERE id = 4;

Error

ERROR 3819 (HY000): Check constraint 'chk_salary' is violated.

Why: the table has CONSTRAINT chk_salary CHECK (salary > 0). Fix: a value that passes the rule. (MariaDB reports the same problem as ERROR 4025 ... CONSTRAINT `chk_salary` failed.)

ERROR 1451: Cannot delete or update a parent row

DELETE FROM authors WHERE id = 2;

Error

ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails (`bookstore`.`books`, CONSTRAINT `fk_books_author` FOREIGN KEY (`author_id`) REFERENCES `authors` (`id`) ON DELETE RESTRICT ON UPDATE CASCADE)

Why: George Orwell (id 2) still has books, and fk_books_author is ON DELETE RESTRICT. The message names the child table, the constraint and the columns. Fix: deal with the children first (here, delete or reassign the books, which themselves have order lines), or, if the design really wants it, define the foreign key with ON DELETE CASCADE or SET NULL. Deleting an author with no books works:

START TRANSACTION;
DELETE FROM authors WHERE id = 10;   -- Isaac Asimov has no books
ROLLBACK;

ERROR 1452: Cannot add or update a child row

INSERT INTO books (title, author_id, price) VALUES ('Foundation', 99, 9.99);

Error

ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails (`bookstore`.`books`, CONSTRAINT `fk_books_author` FOREIGN KEY (`author_id`) REFERENCES `authors` (`id`) ON DELETE RESTRICT ON UPDATE CASCADE)

Why: there is no author with id 99. Fix: look up (or insert) the parent row first, then use its real id:

SELECT id, name FROM authors WHERE name = 'Isaac Asimov';

START TRANSACTION;
INSERT INTO books (title, author_id, price) VALUES ('Foundation', 10, 9.99);
ROLLBACK;

ERROR 1175: You are using safe update mode

Try it: MySQL Workbench turns safe updates on by default; in the mysql client it is --safe-updates or this setting.

SET SESSION sql_safe_updates = 1;
UPDATE books SET price = price + 1;

Error

ERROR 1175 (HY000): You are using safe update mode and you tried to update a table without a WHERE that uses a KEY column.

Why: safe mode refuses UPDATE and DELETE statements whose WHERE does not use a key, because they usually change every row by accident. Fix: add a WHERE on a key column. Switch the protection off only for a statement you have checked:

START TRANSACTION;
UPDATE books SET price = price + 1 WHERE id = 5;
ROLLBACK;
SET SESSION sql_safe_updates = 0;

🔐 Transaction & Locking Errors

Background: Lesson 7.2: Transactions. These need two connections; the blocks are labeled "session A" and "session B" (two terminal windows).

ERROR 1205: Lock wait timeout exceeded

Session A changes a row and does not commit yet:

START TRANSACTION;
UPDATE books SET price = 15.49 WHERE id = 1;

Session B tries to change the same row and waits for A's lock (50 seconds by default; 5 on the test server used for this page):

UPDATE bookstore.books SET price = 13.99 WHERE id = 1;

Error

ERROR 1205 (HY000): Lock wait timeout exceeded; try restarting transaction

Fix: keep transactions short and always finish them with COMMIT or ROLLBACK; a forgotten open transaction in another window (or in phpMyAdmin or Workbench) is the usual culprit. Then retry the statement. Session A ends its transaction:

ROLLBACK;

ERROR 1213: Deadlock found when trying to get lock

Session A updates book 1 and then book 2; at the same moment session B updates book 2 and then book 1. Each waits for the other, so InnoDB picks one transaction as the victim, rolls it back, and the other continues. What the victim sees:

ERROR 1213 (40001): Deadlock found when trying to get lock; try restarting transaction

Fix: the transaction was rolled back, so run it again from START TRANSACTION (applications retry automatically). To make deadlocks rare, touch rows in the same order everywhere (for example, always by ascending id) and keep transactions short. SHOW ENGINE INNODB STATUS\G describes the latest deadlock.

🔌 Connection & Access Errors

Background: Lesson 1.2: Installing MySQL and Lesson 7.4: User Management & Permissions. Most of these happen while logging in, or while logged in as a limited account, so they are shown as the terminal prints them. Installation problems have their own page: Troubleshooting.

ERROR 1045: Access denied for user

$ mysql -u bookstore_app -p
Enter password:
ERROR 1045 (28000): Access denied for user 'bookstore_app'@'localhost' (using password: YES)

Common causes: a wrong password; a user name that does not exist; an account created for a different host ('app'@'%' versus 'app'@'localhost' are two different accounts); using password: NO means you forgot -p. On Ubuntu's own mysql-server package, root logs in through the operating system (sudo mysql) rather than a password. Fix (as an administrator):

CREATE USER 'bookstore_app'@'localhost' IDENTIFIED BY 'Replace-With-A-Long-Passphrase-1';
SELECT user, host, plugin FROM mysql.user WHERE user = 'bookstore_app';
ALTER USER 'bookstore_app'@'localhost' IDENTIFIED BY 'Another-Long-Passphrase-2';   -- reset the password

ERROR 1396: Operation CREATE USER failed

CREATE USER 'bookstore_app'@'localhost' IDENTIFIED BY 'Replace-With-A-Long-Passphrase-1';

Error

ERROR 1396 (HY000): Operation CREATE USER failed for 'bookstore_app'@'localhost' (User account already exists)

Why: that exact account ('bookstore_app'@'localhost') already exists; DROP USER of an account that does not exist fails with the same number. Fix: CREATE USER IF NOT EXISTS / DROP USER IF EXISTS, or ALTER USER to change the existing one.

ERROR 1142: Command denied to user

Logged in as a reporting account that only has SELECT:

mysql> DELETE FROM books WHERE id = 11;
ERROR 1142 (42000): DELETE command denied to user 'report_user'@'localhost' for table 'books'

Why: the account lacks that privilege on that table. That is often exactly right (least privilege). Fix, if the account really needs it, as an administrator:

CREATE USER 'report_user'@'localhost' IDENTIFIED BY 'Replace-With-A-Long-Passphrase-3';
GRANT SELECT ON bookstore.* TO 'report_user'@'localhost';
SHOW GRANTS FOR 'report_user'@'localhost';
GRANT DELETE ON bookstore.books TO 'report_user'@'localhost';

ERROR 1044: Access denied for user to database

mysql> USE mysql;
ERROR 1044 (42000): Access denied for user 'report_user'@'localhost' to database 'mysql'
mysql> CREATE DATABASE reports;
ERROR 1044 (42000): Access denied for user 'report_user'@'localhost' to database 'reports'

Why: the account has no privileges at all on that database. Fix: work in the database you were granted, or have an administrator grant what is needed (GRANT ... ON reports.* TO ...).

ERROR 1227: Access denied; you need (at least one of) the ... privilege(s)

mysql> SET GLOBAL max_connections = 500;
ERROR 1227 (42000): Access denied; you need (at least one of) the SUPER or SYSTEM_VARIABLES_ADMIN privilege(s) for this operation
mysql> CREATE USER 'x'@'localhost';
ERROR 1227 (42000): Access denied; you need (at least one of) the CREATE USER privilege(s) for this operation

Why: server-wide operations need administrative privileges that ordinary accounts should not have. Fix: ask an administrator (or use your admin account) for that one task.

ERROR 1524: Plugin 'mysql_native_password' is not loaded

CREATE USER 'legacy_app'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Replace-With-A-Long-Passphrase-4';

Error

ERROR 1524 (HY000): Plugin 'mysql_native_password' is not loaded

Why: older tutorials (and old PHP advice) switch accounts to mysql_native_password. That plugin is removed in MySQL 9.x and disabled by default in 8.4. Fix: keep the default caching_sha2_password, which current clients and connectors support (PHP 7.4+, Python, Node.js, Java, Workbench, phpMyAdmin 5); upgrade any tool that cannot log in:

CREATE USER 'legacy_app'@'localhost' IDENTIFIED BY 'Replace-With-A-Long-Passphrase-4';
SELECT user, plugin FROM mysql.user WHERE user = 'legacy_app';

Output

+------------+-----------------------+
| user       | plugin                |
+------------+-----------------------+
| legacy_app | caching_sha2_password |
+------------+-----------------------+

ERROR 1819: Your password does not satisfy the current policy requirements

mysql> CREATE USER 'clerk'@'localhost' IDENTIFIED BY 'password';
ERROR 1819 (HY000): Your password does not satisfy the current policy requirements

Why: the server has the validate_password component installed (some installers and Linux packages enable it, with the MEDIUM policy: at least 8 characters with upper and lower case letters, a digit and a symbol). Fix: use a stronger password; SHOW VARIABLES LIKE 'validate_password%'; shows the exact rules. Do not weaken the policy to get past it.

ERROR 2002: Can't connect to local MySQL server through socket

$ mysql -u root -p
ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/var/run/mysqld/mysqld.sock' (2)

Why: on Linux and macOS, localhost means "through the socket file", and the server is not running (or uses another socket path). The number in parentheses is the operating system's error: (2) means the file does not exist. Fix: start the server; see Troubleshooting: MySQL Service Problems.

ERROR 2003: Can't connect to MySQL server on 'host:port'

$ mysql -h 127.0.0.1 -P 3306 -u root -p
ERROR 2003 (HY000): Can't connect to MySQL server on '127.0.0.1:3306' (111)

Why: nothing accepted the TCP connection. (111) means "connection refused" (no server listening on that port); (110) means "timed out" (usually a firewall); Windows shows (10061) for refused. Fix: start the server; check the port (Docker: did you publish it with -p 3306:3306?); for a remote server, check bind-address and the firewall (Troubleshooting: Connection Issues).

ERROR 2005: Unknown MySQL server host

$ mysql -h db.invalid -u root -p
ERROR 2005 (HY000): Unknown MySQL server host 'db.invalid' (-2)

Fix: the host name does not resolve: check its spelling, or use the IP address.

📦 Import & Export Errors

Background: Lesson 8.1: Importing & Exporting Data. The server reads and writes files only inside the folder named by secure_file_priv; on Linux packages that is /var/lib/mysql-files/.

ERROR 1290: The MySQL server is running with the --secure-file-priv option

SELECT id, title, price INTO OUTFILE '/tmp/books.csv' FROM books;

Error

ERROR 1290 (HY000): The MySQL server is running with the --secure-file-priv option so it cannot execute this statement

Why: /tmp is outside the allowed folder. Fix: ask the server where it may write, and use that folder:

SHOW VARIABLES LIKE 'secure_file_priv';
SELECT id, title, price INTO OUTFILE '/var/lib/mysql-files/books.csv'
FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"'
FROM books;

If secure_file_priv is NULL, file import and export through the server are disabled completely; use mysqldump, the client's LOAD DATA LOCAL, or a GUI tool instead.

ERROR 1086: File already exists

SELECT id, title, price INTO OUTFILE '/var/lib/mysql-files/books.csv' FROM books;

Error (the folder shown will differ on your server)

ERROR 1086 (HY000): File '/var/lib/mysql-files/books.csv' already exists

Why: INTO OUTFILE never overwrites a file (a safety feature). Fix: choose a new file name, or delete the old file in a terminal (sudo rm /var/lib/mysql-files/books.csv) and run the export again.

ERROR 13: Can't get stat of file (OS errno ...)

LOAD DATA INFILE '/var/lib/mysql-files/new_books.csv'
INTO TABLE categories
FIELDS TERMINATED BY ','
(name, description);

Error (the folder shown will differ on your server)

ERROR 13 (HY000): Can't get stat of '/var/lib/mysql-files/new_books.csv' (OS errno 2 - No such file or directory)

Why: the server looks for the file on the server's own disk: OS errno 2 means it is not there (a wrong name, or the file is on your machine, not the server's); OS errno 13 - Permission denied means the mysql system user may not read it. Fix: copy the file into the secure_file_priv folder and make it readable (sudo cp new_books.csv /var/lib/mysql-files/), or read it from the client side with LOAD DATA LOCAL INFILE.

ERROR 3948: Loading local data is disabled

mysql> LOAD DATA LOCAL INFILE 'new_books.csv' INTO TABLE books_import ...;
ERROR 3948 (42000): Loading local data is disabled; this must be enabled on both the client and server sides

Why: the server has local_infile switched off (the default). Fix: an administrator turns it on, then reconnect with the client option (next error):

SHOW GLOBAL VARIABLES LIKE 'local_infile';
SET GLOBAL local_infile = ON;

ERROR 2068: LOAD DATA LOCAL INFILE file request rejected

mysql> LOAD DATA LOCAL INFILE 'new_books.csv' INTO TABLE books_import ...;
ERROR 2068 (HY000): LOAD DATA LOCAL INFILE file request rejected due to restrictions on access.

Why: this time the client refuses (a 2000-range number means a client error). Fix: start the client with the option:

mysql --local-infile=1 -u root -p bookstore

⚙️ Procedure & Function Errors

Background: Lesson 7.1: Stored Procedures & Functions.

ERROR 1064 near '' at line 3: the missing DELIMITER

CREATE PROCEDURE list_cheap_books()
BEGIN
    SELECT title, price FROM books WHERE price < 9 ORDER BY price;
END;

Error

ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near '' at line 3
ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'END' at line 1

Why: the client sends everything up to the first ;, so the server receives a procedure that stops in the middle of its body (the '' after "near" means "at the very end"). The leftover END; then fails on its own. Fix: change the delimiter around the definition (phpMyAdmin and Workbench have a delimiter field or handle this for you):

DELIMITER //
CREATE PROCEDURE list_cheap_books()
BEGIN
    SELECT title, price FROM books WHERE price < 9 ORDER BY price;
END //
DELIMITER ;

CALL list_cheap_books();

Output

+------------------------+-------+
| title                  | price |
+------------------------+-------+
| Pride and Prejudice    |  7.99 |
| Animal Farm            |  8.49 |
| The Great Gatsby       |  8.99 |
| The Catcher in the Rye |  8.99 |
+------------------------+-------+

ERROR 1304: PROCEDURE already exists

DELIMITER //
CREATE PROCEDURE list_cheap_books()
BEGIN
    SELECT title FROM books WHERE price < 9;
END //
DELIMITER ;

Error

ERROR 1304 (42000): PROCEDURE list_cheap_books already exists

Fix: MySQL has no CREATE OR REPLACE PROCEDURE. Drop it first (DROP PROCEDURE IF EXISTS list_cheap_books;) and create it again, or use CREATE PROCEDURE IF NOT EXISTS to keep the existing one.

ERROR 1305: PROCEDURE does not exist

CALL list_cheap_book();

Error

ERROR 1305 (42000): PROCEDURE bookstore.list_cheap_book does not exist

Why: a typo, or the procedure lives in another database (procedures belong to a database, like tables). Fix: SHOW PROCEDURE STATUS WHERE Db = 'bookstore'; lists the real names.

ERROR 1318: Incorrect number of arguments

CALL list_cheap_books(9);

Error

ERROR 1318 (42000): Incorrect number of arguments for PROCEDURE bookstore.list_cheap_books; expected 0, got 1

Fix: pass exactly the parameters the definition declares (SHOW CREATE PROCEDURE list_cheap_books\G), including a variable such as @result for each OUT parameter.

DROP PROCEDURE IF EXISTS list_cheap_books;

ERROR 1418: This function has none of DETERMINISTIC, NO SQL, or READS SQL DATA

DELIMITER //
CREATE FUNCTION with_tax(p_price DECIMAL(8, 2))
RETURNS DECIMAL(8, 2)
BEGIN
    RETURN ROUND(p_price * 1.08, 2);
END //
DELIMITER ;

Error

ERROR 1418 (HY000): This function has none of DETERMINISTIC, NO SQL, or READS SQL DATA in its declaration and binary logging is enabled (you *might* want to use the less safe log_bin_trust_function_creators variable)

Why: binary logging is on by default, so MySQL must know whether a function is safe to replay. Fix: declare what the function does: DETERMINISTIC (same input, same output), READS SQL DATA (reads tables) or NO SQL. Do not reach for log_bin_trust_function_creators.

DELIMITER //
CREATE FUNCTION with_tax(p_price DECIMAL(8, 2))
RETURNS DECIMAL(8, 2)
DETERMINISTIC
BEGIN
    RETURN ROUND(p_price * 1.08, 2);
END //
DELIMITER ;

SELECT title, price, with_tax(price) AS price_with_tax FROM books WHERE id <= 3 ORDER BY id;
DROP FUNCTION with_tax;

🧾 JSON Errors

Background: Lesson 7.3: JSON Columns. Setup, as in that lesson:

ALTER TABLE books ADD COLUMN attributes JSON;

ERROR 3140: Invalid JSON text

UPDATE books SET attributes = '{format: paperback}' WHERE id = 1;

Error

ERROR 3140 (22032): Invalid JSON text: "Missing a name for object member." at position 1 in value for column 'books.attributes'.

Why: JSON needs double quotes around names and text values. Fix: write valid JSON, or let MySQL build it:

UPDATE books SET attributes = '{"format": "paperback"}' WHERE id = 1;
UPDATE books SET attributes = JSON_OBJECT('format', 'hardcover') WHERE id = 6;
SELECT title, attributes FROM books WHERE id IN (1, 6) ORDER BY id;

Output

+------------+-------------------------+
| title      | attributes              |
+------------+-------------------------+
| Dune       | {"format": "paperback"} |
| The Hobbit | {"format": "hardcover"} |
+------------+-------------------------+

ERROR 3143: Invalid JSON path expression

SELECT JSON_EXTRACT(attributes, 'format') FROM books WHERE id = 1;

Error

ERROR 3143 (42000): Invalid JSON path expression. The error is around character position 1.

Fix: paths start at $, the whole document: '$.format', '$.awards[0]'.

SELECT title, attributes->>'$.format' AS format FROM books WHERE id = 1;
ALTER TABLE books DROP COLUMN attributes;

🧭 General Debugging Tips

✅ Read the whole message

The number tells you the kind of problem, the message usually names the exact column, value, key or constraint, and near '...' points at the spot in a syntax error. Error numbers from 2000 to 2999 come from the client (connection problems); most others come from the server.

✅ Look at warnings too

When MySQL prints Query OK, 1 row affected, 1 warning, run SHOW WARNINGS; right away: it explains what was converted, truncated or deprecated.

✅ Check your context

SELECT DATABASE();          -- which database am I in?
SELECT CURRENT_USER();      -- which account am I using?
SHOW TABLES;                -- what exists here?
DESCRIBE books;             -- what are the real column names and types?
SHOW CREATE TABLE books\G   -- keys, constraints and their names

✅ Look up an error number in a terminal

The perror tool that comes with the MySQL server prints the message pattern for any number:

perror 1452
# MySQL error code MY-001452 (ER_NO_REFERENCED_ROW_2): Cannot add or update a child row: a foreign key constraint fails%.192s

✅ Test before you modify

Run a SELECT with the same WHERE before an UPDATE or DELETE, and practice risky changes inside START TRANSACTION ... ROLLBACK.

✅ Start small, build up

If a long query fails, cut it down to the FROM and one column, then add the joins, WHERE, GROUP BY and the rest one at a time until the error comes back. The last piece you added is the problem.
