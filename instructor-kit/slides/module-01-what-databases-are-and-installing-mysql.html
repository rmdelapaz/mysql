1.1

What Is a Database?

Why one big sheet stops working, and what replaces it.

1.1 · Mental model

The bookshop that outgrew its sheet

  • One row per order, the customer's name typed every time
  • At 5,000 orders: three spellings of Alice, Bob in two cities
  • No rules: "about 26" in the total column
  • Two people save the file: one loses their work
WHY A database stores each fact once and refuses bad data.
1.1 · Mental model

Your app never touches the files

  1. Your application (or you, in a client) sends SQL
  2. The DBMS, the MySQL server, reads and writes, checks the rules
  3. The database files on disk: only the server touches them
WHY MySQL is the server. A database such as bookstore lives inside it.
1.1 · Tables and keys

Store each fact once, point with a key

  • Table: one kind of thing · row: one thing · column: one typed fact
  • Primary key customers.id: unique, never empty
  • Foreign key orders.customer_id: points to a customer
  • Fix Alice's email once: every order is right
1.1 · Code

A practice database and a table

CREATE DATABASE preview_shop;   -- a new, empty database
USE preview_shop;               -- work inside it from now on
CREATE TABLE customers (
    id         INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50)  NOT NULL,
    last_name  VARCHAR(50)  NOT NULL,
    email      VARCHAR(100) NOT NULL UNIQUE,
    city       VARCHAR(50)
);
Database changed
WHY NOT NULL = required · UNIQUE = no two alike · AUTO_INCREMENT = MySQL picks the id

Update: Bob moves to Boston

UPDATE customers
SET city = 'Boston'
WHERE id = 2;

WATCH No WHERE: every row changes. Read the WHERE line before you press Enter.

1.1 · The database says no

Three refused rows

INSERT ... VALUES (1, 'Dave', ...);      -- id 1 is Alice's
INSERT ... VALUES ('abc', 'Dave', ...);  -- text in an INT
INSERT ... (first_name, email) ...;     -- no last_name
ERROR 1062 (23000): Duplicate entry '1' for key 'customers.PRIMARY'
ERROR 1366 (HY000): Incorrect integer value: 'abc' for column 'id' at row 1
ERROR 1364 (HY000): Field 'last_name' doesn't have a default value
WHY A spreadsheet takes all three. Read the number first, then the reason.

1.2

Installing MySQL

A server, a client, and proof that they talk.

1.2 · Mental model

Two programs and a door number

  • Server mysqld: runs in the background, owns the data
  • It listens on a port: 3306
  • Client mysql: knocks on that door with your SQL
  • Same laptop today; different machines at work
WHY Ask the SERVER which version it is, not the client.
1.2 · Versions

Install 9.7 LTS on purpose

  • Windows: MSI + MySQL Configurator, then add bin to PATH
  • macOS: brew install mysql@9.7 or the DMG
  • Linux: MySQL's APT or Yum repository
  • Anywhere: docker run ... mysql:9.7
WATCH brew install mysql and mysql:latest are 26.x; XAMPP is MariaDB.
1.2 · Install clinic · 25 minutes

Fix by platform

  • Windows: PATH, then is the MySQL97 service running?
  • macOS: the keg-only PATH line, brew services start mysql@9.7
  • Ubuntu's own package: sudo mysql, then set a password
  • Docker: port taken? -p 3307:3306 and -h 127.0.0.1 -P 3307
  • Done = the environment check says READY
1.2 · Code

Connect, then ask the server

SELECT VERSION() AS version,
       CURRENT_USER() AS logged_in_as,
       @@character_set_server AS charset;
+---------+----------------+---------+
| version | logged_in_as   | charset |
+---------+----------------+---------+
| 9.7.2   | root@localhost | utf8mb4 |
+---------+----------------+---------+
WHY Any 9.7.x is right. Through Docker's port you are root@%.
1.2 · Code

What is in a fresh server?

SHOW DATABASES;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
WHY Four system databases. Never put your own tables in them.
1.2 · Code

How does root log in?

SELECT user, host, plugin
FROM mysql.user
WHERE user = 'root'
ORDER BY host;
+------+-----------+-----------------------+
| user | host      | plugin                |
+------+-----------+-----------------------+
| root | localhost | caching_sha2_password |
+------+-----------+-----------------------+
WHY Never mysql_native_password: it is gone in 9.x.
1.2 · Old advice

Two forum fixes that fail on 9.7

CREATE USER 'legacy_app'@'localhost'
    IDENTIFIED WITH mysql_native_password BY 'placeholder-password';
SELECT @@default_authentication_plugin;
ERROR 1524 (HY000): Plugin 'mysql_native_password' is not loaded
ERROR 1193 (HY000): Unknown system variable 'default_authentication_plugin'
RULE Update the client; never weaken the server.
1.2 · Error triage

Which number?

  • command not found: the client is not on your PATH
  • 1045: the server answered and refused your password
  • 2002 / 2003: nothing answered: server stopped, or wrong address
  • Docker on macOS/Linux: 127.0.0.1, not localhost
