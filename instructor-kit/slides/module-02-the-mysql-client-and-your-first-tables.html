1.3

MySQL CLI & phpMyAdmin

Find your way around any server, and run a whole file.

1.3 · Mental model

One server, many clients

  • A client sends SQL and shows the answer: mysql, phpMyAdmin, Workbench
  • Same statement, same result, whichever client
  • SQL goes to the server: SHOW, USE, DESCRIBE, SELECT
  • Client commands stay in the mysql program: \G, SOURCE, help, exit
WHY phpMyAdmin has never heard of the client commands.
1.3 · Logging in

In, out, and the prompts

  • mysql -u root -p: no space and no password after -p
  • Out: exit, \q or Ctrl+D · Ctrl+C cancels a statement
  • mysql> ready · -> waiting for ; · '> a quote is open
  • \c throws away what you are typing
WATCH -p secret with a space: ERROR 1049 Unknown database 'secret'.

1.3 · Errors

Read the message from the left

WHY 1146 names the database it looked in. 1064: near '...' points at the spot.
1.3 · Files

Save SQL, run it two ways

SOURCE ~/mysql-course/hello.sql                # at the mysql> prompt
mysql -u root -p < ~/mysql-course/hello.sql     # from the shell
mysql -t -u root -p < ~/mysql-course/hello.sql  # boxes back
  • From the shell = batch mode: tab-separated text without -t
  • MySQL 9.x ignores \G and SOURCE there unless --commands
  • PowerShell has no <: cmd /c
WATCH Windows paths in SOURCE: forward slashes.

2.1

Creating Databases & Tables

From exploring to building: the bookstore's first three tables.

2.1 · Mental model

Cabinet, drawer, folder

  • Server = cabinet · database = drawer · table = folder
  • utf8mb4: every character · never utf8 (3 bytes)
  • Name the collation: utf8mb4_unicode_ci sorts the same on 9.7, 8.4, MariaDB
  • Names: lowercase, snake_case, plural tables, id, customer_id
NAMES Not order, not Books, not tbl_book.
2.1 · Code

Create the drawer, settings named

CREATE DATABASE bookstore
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
SELECT SCHEMA_NAME, DEFAULT_CHARACTER_SET_NAME AS charset,
       DEFAULT_COLLATION_NAME AS collation
FROM information_schema.SCHEMATA
WHERE SCHEMA_NAME = 'bookstore';
+-------------+---------+--------------------+
| SCHEMA_NAME | charset | collation          |
+-------------+---------+--------------------+
| bookstore   | utf8mb4 | utf8mb4_unicode_ci |
+-------------+---------+--------------------+
WHY Again without IF NOT EXISTS: ERROR 1007 database exists.
2.1 · Code

The first folder: books

CREATE TABLE books (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    title       VARCHAR(200) NOT NULL,
    author      VARCHAR(100) NOT NULL,
    price       DECIMAL(8, 2) NOT NULL,
    pages       INT,
    published   DATE,
    in_stock    BOOLEAN DEFAULT TRUE
);
WHY Name, type, rule on every line. Commas between columns, none after the last.

2.1 · Code

IF NOT EXISTS keeps the old table

CREATE TABLE IF NOT EXISTS books (
    id INT PRIMARY KEY
);
SHOW WARNINGS;
+-------+------+------------------------------+
| Level | Code | Message                      |
+-------+------+------------------------------+
| Note  | 1050 | Table 'books' already exists |
+-------+------+------------------------------+
WHY Nothing changes: a Note. ALTER TABLE is how you change a table.
2.1 · ALTER TABLE

Change the structure, keep the rows

ALTER TABLE t ADD COLUMN col TYPE AFTER other;
ALTER TABLE t RENAME COLUMN old TO new;
ALTER TABLE t MODIFY COLUMN col FULL_DEFINITION;
ALTER TABLE t CHANGE COLUMN old new FULL_DEFINITION;
ALTER TABLE t DROP COLUMN col;
ALTER TABLE t RENAME TO new_name;
WHY Several changes in one statement: separate them with commas.
2.1 · The silent trap

MODIFY replaces everything

ALTER TABLE books MODIFY COLUMN title VARCHAR(250);
SHOW COLUMNS FROM books LIKE 'title';
+-------+--------------+------+-----+---------+-------+
| Field | Type         | Null | Key | Default | Extra |
+-------+--------------+------+-----+---------+-------+
| title | varchar(250) | YES  |     | NULL    |       |
+-------+--------------+------+-----+---------+-------+
WATCH No error, no warning: title lost NOT NULL. Repeat every rule, then DESCRIBE.
2.1 · Rows, tables, databases

Empty, remove, start over

TRUNCATE TABLE tall rows gone · table kept · ids back to 1
DROP TABLE trows and table gone
DROP DATABASE devery table gone, no undo
CREATE TABLE t2 LIKE tan empty copy to practice on
WATCH After dropping the database you are in: SELECT DATABASE(); is NULL.
2.1 · Errors

Five numbers to know

1007 / 1050database / table already exists
1046no database selected: USE, or db.table
1064cannot read it: a reserved word, a stray comma
1146no such table (it names the database it looked in)
1049no database by that name
WHY CREATE TABLE order: 1064. Call it orders.
