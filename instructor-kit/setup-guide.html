MySQL Foundations · Before You Begin

Set Up MySQL for the Course

About half an hour to do before the first session: install MySQL 9.7 LTS, give its administrator account a strong password, make a course folder and run a short check that tells you (and your instructor) whether your laptop is ready. These are the same steps as Lesson 1.2 on the course site (rays-mysql.netlify.app, lesson "Installing MySQL"), which shows every step with its expected output. Session 1 then spends its time on databases instead of progress bars.

⏱ 20–40 min, mostly downloading No SQL needed yet Windows · Mac · Linux · Docker Free software
Please do this at home, not in class

The installer is a download of a few hundred megabytes, and venue Wi-Fi is rarely up to twenty people doing that at once. If a step fails, keep going with the others and bring the exact error message (a screenshot is fine) to Session 1: its first half hour includes an environment check, and there is an install clinic after the break.

What You Need

  • A laptop (Windows 10/11, macOS, or Linux) and its charger, with permission to install software (administrator rights) and about 1.5 GB of free disk space. Chromebooks, tablets and locked work laptops cannot run the course comfortably: talk to your instructor first.
  • A terminal: PowerShell on Windows, Terminal on macOS, your usual terminal on Linux. You will type a few commands into it; the course explains each one.
  • A plain-text editor for .sql files. VS Code (free) works well. Not Word or TextEdit in rich-text mode: their curly quotes break SQL.
  • The environment check: three small files from labs/module-01/l1_0-orientation/ that your instructor sends with this guide (check_environment.sql, check_environment.sh, check_environment.ps1).
  • A learning journal: a plain text file or a paper notebook. Every lesson ends with a journal prompt.
  • A password manager (or a safe place) for the MySQL root password you are about to choose.

Am I Ready for This Course?

MySQL Foundations starts from zero: no SQL and no programming are needed. It builds on everyday spreadsheet and computer skills. You are ready if you can:

  • ☐ Filter a spreadsheet to the rows where a column has a certain value, and sort it by a column
  • ☐ Say what "city is Chicago AND total over 20" keeps that "city is Chicago OR total over 20" does not
  • ☐ Write a formula column such as price times quantity, and notice what happens with an empty cell
  • ☐ Install a program, find a downloaded file, and say which folder a file is in (for example Downloads/bookstore.sql)
  • ☐ Open a terminal, and copy a command into it exactly

Two or more unchecked? Come anyway and tell your instructor. Session 1 includes a short, ungraded diagnostic on these same skills, so your instructor knows where to help.

Set Up in 5 Steps

1

Choose the version and one path

~2 min

The course uses MySQL 9.7 LTS (long-term support), the free MySQL Community Server. Every output on the lesson pages was produced on 9.7, so yours will match.

  • Ask for 9.7 by name. After 9.7, MySQL switched to calendar version numbers (year.month): its frequent innovation releases are numbered like 26.x, and "latest" on a download page, brew install mysql or mysql:latest usually means one of those. They work, but some outputs will differ from the pages.
  • MySQL 8.4 LTS also runs the course almost everywhere. MySQL 8.0, which many old tutorials show, is past its end of life: if a package offers you 8.0, use the steps below instead.
  • XAMPP ships MariaDB, not MySQL, even though its button says "MySQL". MAMP ships MySQL, usually an older series. Both can follow most of the course (the lessons' version notes explain the differences), but for matching outputs install MySQL 9.7 itself.
  • One server per port. If MySQL, MariaDB, XAMPP or MAMP is already installed and running, stop it first: two servers cannot both listen on port 3306.

2

Install MySQL 9.7

~15–30 min
Windows: the MSI installer and MySQL Configurator
  1. Download. At dev.mysql.com/downloads/mysql (MySQL Community Server), choose 9.7.x LTS and Microsoft Windows, then the Windows (x86, 64-bit), MSI Installer. "No thanks, just start my download" skips the account sign-up.
  2. Install. Run the .msi, accept the license, choose Typical, confirm the administrator prompt. Leave "run MySQL Configurator" checked at the end. (If it asks for the Visual C++ Redistributable, install the current x64 one from Microsoft and run the MSI again.)
  3. Configure. In MySQL Configurator: config type Development, port 3306; type a strong root password twice and store it; keep "Configure MySQL Server as a Windows Service" and "Start at System Startup" checked and note the service name (something like MySQL97); skip the sample databases; Execute, wait for the green checks, Finish.
  4. Put the client on your PATH. The MSI does not. Start ▸ "Edit the system environment variables" ▸ Environment Variables… ▸ your user Path ▸ Edit ▸ New, and add C:\Program Files\MySQL\MySQL Server 9.7\bin. OK three times, then open a new PowerShell window and check with mysql --version.

Start and stop later: the Services app, or Get-Service MySQL*, Start-Service MySQL97, Stop-Service MySQL97 in an administrator PowerShell.

macOS: Homebrew (Option A) or the DMG package (Option B)

Option A, Homebrew. Ask for the 9.7 series by name (plain brew install mysql gives an innovation release). Versioned formulae are "keg-only", so add their folder to your PATH:

brew install mysql@9.7
echo 'export PATH="$(brew --prefix)/opt/mysql@9.7/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
mysql --version
brew services start mysql@9.7

Homebrew creates root without a password: Step 3 fixes that. Stop it later with brew services stop mysql@9.7.

Option B, the DMG. At dev.mysql.com/downloads/mysql choose 9.7.x LTS, macOS, and the DMG Archive for your processor (ARM, 64-bit for Apple silicon, x86, 64-bit for Intel; Apple menu ▸ About This Mac tells you). Run the .pkg, set a strong root password near the end, then put the programs on your PATH:

echo 'export PATH="/usr/local/mysql/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
mysql --version

The DMG starts MySQL automatically and adds a MySQL pane to System Settings for starting and stopping it.

Linux: MySQL's APT or Yum repository

Your distribution's own package is usually not MySQL 9.7. Check with apt policy mysql-server:

Distribution packageWhat you get
mysql-server on Ubuntu 22.04 and 24.04MySQL 8.0 (past its end of life)
mysql-server on Ubuntu 26.04MySQL 8.4 LTS
default-mysql-server on DebianMariaDB, not MySQL
MySQL's own APT or Yum repositorythe series you pick: 9.7 LTS

Ubuntu and Debian. Download mysql-apt-config_…_all.deb from dev.mysql.com/downloads/repo/apt. Installing it opens a text menu: under the server entry choose 9.7 LTS, then Ok. Set a strong root password when the install asks.

sudo dpkg -i ~/Downloads/mysql-apt-config_*_all.deb
sudo apt update
sudo apt install mysql-server
systemctl status mysql        # look for "active (running)"

Fedora, RHEL, Rocky, AlmaLinux. Download the repository package for your release from dev.mysql.com/downloads/repo/yum, install it with sudo dnf install ./mysql*-community-release-*.rpm, make sure the 9.7 LTS series is the enabled one, then:

sudo dnf install mysql-community-server
sudo systemctl enable --now mysqld
sudo grep 'temporary password' /var/log/mysqld.log

The first start writes a random temporary root password to that log: you change it in Step 3. In WSL, follow the Ubuntu steps inside your Linux terminal (on an old WSL without systemd: sudo service mysql start).

Docker: any operating system

With Docker Desktop (Windows, macOS) or Docker Engine (Linux), the official image is the cleanest install. Choose your own password (on Windows PowerShell, put the command on one line):

docker run --name mysql97 \
  -e MYSQL_ROOT_PASSWORD='choose-a-strong-password' \
  -p 3306:3306 \
  -v mysql97-data:/var/lib/mysql \
  -d mysql:9.7
docker logs mysql97          # wait for "ready for connections ... port: 3306"
docker exec -it mysql97 mysql -u root -p
  • Use the tag mysql:9.7, not mysql:latest (an innovation release). Port 3306 taken? -p 3307:3306.
  • The password counts only on the very first start of the mysql97-data volume; the data survives docker stop, docker start mysql97 and even docker rm.
  • The image contains the mysql client (the last line above). A client installed on the laptop connects with mysql -h 127.0.0.1 -P 3306 -u root -p: use 127.0.0.1, not localhost.
  • After a reboot, open Docker Desktop and run docker start mysql97.
3

Secure the root account, then log in

~5 min

root is MySQL's administrator. It must have a strong password; your instructor will never ask you to share it.

You installed withRoot password nowWhat to do
Windows MSI, macOS DMG, DockerThe one you setNothing more
MySQL APT repositoryThe one you setOptionally sudo mysql_secure_installation
HomebrewNoneRun mysql_secure_installation (answer y to removing anonymous users, remote root and the test database)
Yum repositoryTemporary, from the logLog in with it and change it (below)
Ubuntu's own packageNone: only sudo mysql worksSet a password (below), or better, use MySQL's APT repository

To set the password by hand, open the client (sudo mysql, or mysql -u root -p with the temporary password) and run, with your own password inside the quotes:

ALTER USER 'root'@'localhost'
    IDENTIFIED WITH caching_sha2_password BY 'your-strong-password-here';

Then log in and ask the server who it is. Nothing appears while you type the password; that is normal. Leave with exit.

mysql -u root -p
SELECT VERSION();
+-----------+
| VERSION() |
+-----------+
| 9.7.2     |
+-----------+

Any 9.7.x is right. 8.4.x is fine. 26.x (an innovation release), 8.0.x, or a version containing MariaDB means you are talking to a different server than you meant to: see the problems table below. Never "fix" a login with mysql_native_password: that old method no longer exists in MySQL 9 (error 1524).

Common Install Problems

You see…Try this
Windows: mysql "is not recognized as the name of a cmdlet"The MSI does not add the client to the PATH: Step 2, Windows point 4, then open a new PowerShell window.
macOS: zsh: command not found: mysqlVersioned Homebrew formulae are keg-only: the export PATH=…mysql@9.7/bin… line in ~/.zshrc, then a new Terminal window (DMG: the /usr/local/mysql/bin line).
SELECT VERSION(); says 26.xbrew install mysql or mysql:latest gave you an innovation release. It works; for matching outputs reinstall mysql@9.7 / mysql:9.7.
Ubuntu: version 8.0.x, or root works only with sudo mysqlThe distribution's own package. Add MySQL's APT repository (Step 2), or at least set a password with the ALTER USER statement in Step 3.
ERROR 1045 (28000): Access deniedThe server answered and refused the name or password. Retype it (it is case-sensitive); "using password: NO" means you forgot -p. Docker: the password counts only on the first start of a volume.
ERROR 2002 (socket) or ERROR 2003 (port)Nothing answered: the server is stopped, or you asked the wrong place. Start it (Start-Service MySQL97, brew services start mysql@9.7, sudo systemctl start mysql, docker start mysql97); with Docker use -h 127.0.0.1 -P 3306, not localhost.
docker run: "port is already allocated"Another MySQL, MariaDB, XAMPP or MAMP listens on 3306. Stop it, or publish on another port: -p 3307:3306, then connect with -P 3307.
The check says CHECK … MariaDBXAMPP or a distribution's default package. You can start with it; install MySQL 9.7 when you can.
Windows: the .ps1 "cannot be loaded because running scripts is disabled"Run it exactly as in Step 5, with powershell -ExecutionPolicy Bypass -File … (nothing to change system-wide).
ERROR 1524: Plugin 'mysql_native_password' is not loadedOld advice. Leave out IDENTIFIED WITH mysql_native_password; current clients and phpMyAdmin 5.2 use the default method.
A locked work laptop: nothing can be installedDocker Desktop also needs administrator rights. Ask IT to install MySQL 9.7 before Session 1, or bring a personal laptop; tell your instructor.

Frequently Asked

Do I need to know programming?

No. SQL is the language the course teaches, from the first statement. If you can use a spreadsheet and a file browser, you can start.

I already have XAMPP, MAMP or an older MySQL. Can I keep it?

You can start with it: the environment check tells you what it is. XAMPP's database is MariaDB, and a few lessons (JSON operators, window and EXPLAIN details, some error numbers) will look different. For outputs that match the pages, install MySQL 9.7, and stop the old server first so they do not fight over port 3306.

Do I need phpMyAdmin or MySQL Workbench?

No. The course uses the mysql command-line client, which comes with every install. Lesson 1.3 tours phpMyAdmin; Lesson 1.2 shows how to run it in Docker next to MySQL if you want it.

Is the course data real?

No. The bookstore's customers, orders and staff are invented for the course (the books are real classics). You build the database yourself, step by step, starting in Session 2.

What if a step fails and I cannot fix it?

Come anyway, with the output of the environment check. Session 1 opens with the check and has an install clinic after the break, and you can pair with a neighbor until your machine is ready.

  • ☐ USB sticks or a shared folder (the fallback when venue Wi-Fi fails): the labs/ folder without any *_solution.sql files and without checkpoint-* and part1-assessment until they are used; and the installers: the Windows MSI (x86, 64-bit), both macOS DMGs (ARM and x86), the mysql-apt-config package, and for Docker users the image saved with docker save mysql:9.7 -o mysql97.tar (they run docker load -i mysql97.tar).   • ☐ Your own machine: MySQL 9.7 with the same mysql-course folder; the environment check ends with READY (so you can show what it looks like). From the kit folder, python3 labs/check_labs.py module-01 prints PASS on every line (point it at your server with the MYSQL_LABS_* variables in the README); run each session's check before that session.
  • ☐ Projector: a terminal in mysql-course at 18 pt or more, logged out (you log in during the Lesson 1.2 demo), a second terminal already in the mysql> client, the session's deck from slides/ and the lesson pages open in a browser.
  • ☐ The room: a power socket for every laptop (bring power strips), a whiteboard, sticky notes (help flags and exit tickets), printed workbooks or a shared PDF, and Wi-Fi for the lesson pages. After Session 1 no session needs a download.
  • ☐ Install trouble on the day: do not debug one machine in front of the room. Two minutes per machine during the opening check, then pair the learner with a ready neighbor; the install clinic after the break is for the rest. PATH and a stopped server are one-minute fixes; a full download is not done on venue Wi-Fi. The Session 1 facilitator guide has the full trap table.
  • ☐ Locked work laptops: every install path needs administrator rights (Docker Desktop too). Ask the learner's IT team to install MySQL 9.7 before Session 2, or pair the learner for the day; MySQL's Windows ZIP archive runs without installing but needs manual setup, so offer it only with your help.
