Get Ready in Half an Hour

Before the first session: install MySQL 9.7 LTS, set a strong root password, make a course folder, run the check. You need a laptop you can install software on, 1.5 GB free, and a plain-text editor (VS Code). Ask for 9.7 by name ("latest" is a 26.x innovation release, Ubuntu's own package is 8.0, XAMPP is MariaDB) and stop any other MySQL/MariaDB server first. Stuck? The full Setup Guide covers every path and problem.

1 · Install MySQL 9.7 (pick one)

Windows

dev.mysql.com/downloads/mysql ▸ 9.7.x LTS ▸ Windows MSI Installer. Run it (Typical); in MySQL Configurator choose Development, port 3306, a strong root password, Windows Service. Add C:\Program Files\MySQL\MySQL Server 9.7\bin to your user Path and open a new PowerShell.

macOS (Homebrew)
brew install mysql@9.7
echo 'export PATH="$(brew --prefix)/opt/mysql@9.7/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
brew services start mysql@9.7
mysql_secure_installation

The last line sets the root password (answer y). No Homebrew? Use the DMG for your processor.

Ubuntu / Debian (Fedora, RHEL, Rocky, Alma: MySQL's Yum repository, see the full guide)

Get mysql-apt-config_…_all.deb from dev.mysql.com/downloads/repo/apt, choose 9.7 LTS in its menu, set the root password when asked.

sudo dpkg -i ~/Downloads/mysql-apt-config_*_all.deb
sudo apt update
sudo apt install mysql-server
Docker (any system)
docker run --name mysql97 -e MYSQL_ROOT_PASSWORD='choose-a-strong-password' \
  -p 3306:3306 -v mysql97-data:/var/lib/mysql -d mysql:9.7
docker exec -it mysql97 mysql -u root -p

PowerShell: one line. After a reboot: docker start mysql97.

2 · Log in and check the version

mysql -u root -p
SELECT VERSION();

The password does not show as you type. 9.7.x is right (8.4.x is fine); 8.0, 26.x or MariaDB means a different server than you meant. Leave with exit. Never "fix" a login with mysql_native_password: MySQL 9 removed it.

3 · Make the course folder

mkdir -p ~/mysql-course && cd ~/mysql-course          # macOS / Linux
mkdir $HOME\mysql-course; cd $HOME\mysql-course        # Windows PowerShell

Put the three check files from your instructor in labs/module-01/l1_0-orientation/ inside mysql-course. Always start the mysql client from inside this folder. Do not load bookstore.sql yet: you build the bookstore yourself in Lesson 2.1.

4 · Run the check

SystemFrom inside mysql-course, run
macOS, Linux, WSLbash labs/module-01/l1_0-orientation/check_environment.sh
Windowspowershell -ExecutionPolicy Bypass -File labs\module-01\l1_0-orientation\check_environment.ps1
Dockerdocker exec -i mysql97 sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --table' < labs/module-01/l1_0-orientation/check_environment.sql
✅ Done when the last table says READY for MySQL Foundations

Send that table to your instructor. READY WITH NOTES (8.4 or MariaDB) is fine. NOT READY? The line above it says what failed: see the full guide's problems table, or bring the output to Session 1's install clinic.
