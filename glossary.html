📖 Glossary

Plain-language definitions of the terms used in MySQL Foundations, in alphabetical order. Each entry links to the lesson that teaches it; the Cheat Sheet has the matching syntax.

Jump to: A · B · C · D · E · F · G · H · I · J · L · M · N · O · P · Q · R · S · T · U · V · W

A

ACID

The four guarantees of a reliable transaction: Atomicity (all or nothing), Consistency (constraints hold before and after), Isolation (concurrent transactions do not see each other's unfinished work) and Durability (committed changes survive a crash). InnoDB provides all four. See Lesson 7.2: Transactions.

Aggregate Function

A function that turns many rows into one value: COUNT(), SUM(), AVG(), MIN(), MAX(), GROUP_CONCAT(). With GROUP BY it returns one value per group. See Lesson 3.3: Aggregate Functions & GROUP BY.

Alias

A temporary name for a column or table in one query, written with AS: SELECT price * 0.9 AS sale_price FROM books b. Derived tables must have one. A column alias cannot be used in WHERE (error 1054), because WHERE is evaluated first.

ALTER TABLE

The statement that changes an existing table's structure: add, change, rename or drop columns, indexes and constraints. See Lesson 2.1: Creating Databases & Tables.

Anchor Member

The first, non-recursive SELECT of a recursive CTE: the starting rows (for example, the employee with no manager). The recursive member then builds on them. See Lesson 5.1: CTEs & Recursive Queries.

Authentication Plugin

How the server checks a password. MySQL 8.4 and 9.7 use caching_sha2_password for new accounts; the old mysql_native_password is disabled in 8.4 and removed in 9.x. Ubuntu's own package logs root in with auth_socket (your operating-system user) instead of a password. See Lesson 1.2: Installing MySQL and Lesson 7.4: User Management & Permissions.

AUTO_INCREMENT

A column attribute that gives each new row the next number automatically. Typically used on the primary key. LAST_INSERT_ID() returns the value just generated in your session. See Lesson 2.2: Data Types & Constraints.

B

Backup

A copy of your data you can restore after a mistake or a failure. mysqldump makes logical backups: .sql files that recreate the tables and rows. See Lesson 8.1: Importing & Exporting Data.

C

Cardinality

The number of different values in a column (or index). High cardinality (like email) makes an index selective and useful; low cardinality (like in_stock) usually does not. Also used for relationships: one-to-one, one-to-many, many-to-many. See Lesson 6.1: Indexes & Query Optimization.

CASCADE

A foreign key action. ON DELETE CASCADE deletes the child rows when their parent row is deleted; ON UPDATE CASCADE changes the child values when the parent key changes. See Lesson 4.2: Foreign Keys & Referential Integrity.

Character Set

The rules for storing characters as bytes. Use utf8mb4 (all of Unicode, including emoji). MySQL's plain utf8 is the old 3-byte utf8mb3 and is deprecated. See Lesson 2.1: Creating Databases & Tables.

CHECK Constraint

A rule every row must satisfy, such as CHECK (salary > 0). MySQL rejects violating rows with error 3819 (MariaDB: 4025). See Lesson 2.2: Data Types & Constraints.

CLI (Command-Line Interface)

A text interface where you type commands. The mysql client is MySQL's CLI: you type SQL at the mysql> prompt. See Lesson 1.3: MySQL CLI & phpMyAdmin.

Collation

The rules for comparing and sorting text in a character set. A name ending in _ci is case-insensitive ('dune' = 'Dune' is true); _bin compares exact bytes. The course database uses utf8mb4_unicode_ci; MySQL's default is utf8mb4_0900_ai_ci. See Lesson 2.1: Creating Databases & Tables.

Column

A named attribute of a table with one data type (title VARCHAR(200)). Also called a field. See Lesson 1.1: What Is a Database?.

COMMIT

Ends a transaction and makes all its changes permanent. After COMMIT, ROLLBACK can no longer undo them. See Lesson 7.2: Transactions.

Common Table Expression (CTE)

A named, temporary result defined with WITH name AS (SELECT ...) at the start of a statement, which the main query can use like a table. CTEs make long queries readable and can refer to earlier CTEs. See also Recursive CTE. See Lesson 5.1: CTEs & Recursive Queries.

Composite Index

An index on two or more columns, such as (last_name, first_name). Column order matters: it helps queries that filter on the leftmost column(s). See Lesson 6.1: Indexes & Query Optimization.

Constraint

A rule the database enforces on the data: PRIMARY KEY, NOT NULL, UNIQUE, FOREIGN KEY, CHECK (and the related DEFAULT). See Lesson 2.2: Data Types & Constraints.

Correlated Subquery

A subquery that refers to a column of the outer query, so it is evaluated once per outer row: WHERE price = (SELECT MAX(price) FROM books WHERE author_id = b.author_id). See Lesson 3.4: Subqueries & Nested Queries.

CROSS JOIN

A join without a condition: every row of one table combined with every row of the other (the Cartesian product). See Lesson 4.3: Joins.

CRUD

The four basic data operations: Create (INSERT), Read (SELECT), Update (UPDATE), Delete (DELETE). See Lesson 2.3: CRUD Operations.

CSV (Comma-Separated Values)

A plain-text format with one row per line and values separated by commas. The usual way to move data between MySQL and spreadsheets. See Lesson 8.1: Importing & Exporting Data.

D

Database

An organized collection of structured data. In MySQL, a database (also called a schema) is a named container for tables, views, procedures and other objects. See Lesson 1.1: What Is a Database?.

Data Type

What a column can hold and how it is stored: INT, DECIMAL(8, 2), VARCHAR(200), DATE, BOOLEAN, JSON and more. See Lesson 2.2: Data Types & Constraints.

DCL (Data Control Language)

The SQL statements that control access: GRANT and REVOKE. See Lesson 7.4: User Management & Permissions.

DDL (Data Definition Language)

The SQL statements that define structure: CREATE, ALTER, DROP, TRUNCATE, RENAME. In MySQL they commit automatically and cannot be rolled back. See Lesson 2.1: Creating Databases & Tables.

Deadlock

Two transactions each waiting for a lock the other holds. InnoDB detects it, rolls one back (error 1213) and lets the other continue; the application retries the victim. See Lesson 7.2: Transactions.

DEFAULT Role

A role that becomes active automatically when the account logs in, set with SET DEFAULT ROLE. Granted roles that are not default must be switched on with SET ROLE. See Lesson 7.4: User Management & Permissions.

DELIMITER

A mysql client command that changes the statement terminator (for example to //) so a procedure body full of semicolons can be sent as one statement. Not SQL: GUI tools handle it themselves. See Lesson 7.1: Stored Procedures & Functions.

Denormalization

Deliberately adding redundant data to a normalized design to make reads faster, at the cost of more work (and risk) when writing. See Lesson 6.3: Database Design & Normalization.

DENSE_RANK()

A window function that numbers rows by an ordering, giving ties the same number and leaving no gaps (1, 2, 2, 3). Compare RANK() and ROW_NUMBER(). See Lesson 5.2: Window Functions.

Derived Table

A subquery in the FROM clause, used like a temporary table for that one query. It must have an alias (error 1248). See Lesson 3.4: Subqueries & Nested Queries.

DML (Data Manipulation Language)

The SQL statements that read and change rows: SELECT, INSERT, UPDATE, DELETE. See Lesson 2.3: CRUD Operations.

Docker

A tool that runs software in isolated containers. docker run ... mysql:9.7 starts a complete MySQL server without installing it on your system; its data lives in a volume. See Lesson 1.2: Installing MySQL.

E

ER Diagram (Entity-Relationship Diagram)

A picture of the tables (entities), their columns (attributes) and the relationships between them, drawn while designing a database. See Lesson 4.1: Table Relationships.

EXPLAIN

Shows how MySQL plans to run a query: which index it uses, the join order, and an estimate of the rows it will examine. EXPLAIN ANALYZE actually runs the query and reports real timings (MySQL only). See Lesson 6.1: Indexes & Query Optimization.

F

Foreign Key

A column whose values must match a key in another (parent) table, such as books.author_id referencing authors.id. It enforces referential integrity. See Lesson 4.2: Foreign Keys & Referential Integrity.

Full Table Scan

Reading every row of a table to answer a query. Fine for small tables, slow for big ones; EXPLAIN shows it as type: ALL. Often fixed by an index. See Lesson 6.1: Indexes & Query Optimization.

G

GRANT

Gives privileges (such as SELECT or INSERT) on a database, table or column to an account or role. See Lesson 7.4: User Management & Permissions.

GROUP BY

Collapses rows that share the same value(s) into one row per group, so aggregate functions run per group: GROUP BY author_id counts books per author. In MySQL 8.0 and later it does not sort the groups: add ORDER BY. See Lesson 3.3: Aggregate Functions & GROUP BY.

H

HAVING

Filters groups after GROUP BY, using aggregate values: HAVING COUNT(*) > 1. WHERE filters single rows before grouping. See Lesson 3.3: Aggregate Functions & GROUP BY.

I

Index

A sorted lookup structure that lets MySQL find rows without reading the whole table, like the index at the back of a book. Faster reads; a little extra work on every write. See Lesson 6.1: Indexes & Query Optimization.

INNER JOIN

A join that keeps only the rows that have a match in both tables. JOIN alone means INNER JOIN. See Lesson 4.3: Joins.

InnoDB

MySQL's default storage engine: transactions, foreign keys, row-level locking and crash recovery. Every table in this course uses it. See Lesson 7.2: Transactions.

Isolation Level

How much concurrent transactions see of each other's changes: READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ (InnoDB's default) or SERIALIZABLE. Check it with SELECT @@transaction_isolation;. See Lesson 7.2: Transactions.

J

JOIN

Combines rows from two or more tables through related columns: INNER, LEFT, RIGHT and CROSS joins, and self-joins. MySQL has no FULL OUTER JOIN. See Lesson 4.3: Joins.

JSON

A text format for structured documents ({"format": "paperback", "awards": ["Hugo"]}). MySQL's JSON data type validates and stores such documents efficiently; MariaDB treats JSON as LONGTEXT with a validity check. See Lesson 7.3: JSON Columns.

JSON Path

An expression that points into a JSON document, starting at $ (the whole document): '$.format', '$.awards[0]'. Used by JSON_EXTRACT(), -> and ->>. ->> returns plain text and does not exist in MariaDB. See Lesson 7.3: JSON Columns.

JSON_TABLE()

A function that turns parts of a JSON document into rows and typed columns, so you can join and filter them with ordinary SQL. See Lesson 7.3: JSON Columns.

Junction Table

A table that implements a many-to-many relationship with two foreign keys. In the course database, book_categories links books and categories. Also called a bridge, linking or associative table. See Lesson 4.1: Table Relationships.

L

LAG() / LEAD()

Window functions that read a value from the previous (LAG) or next (LEAD) row in the window's order, for example to compare this month's revenue with last month's. See Lesson 5.2: Window Functions.

LAMP Stack

Linux, Apache, MySQL (or MariaDB), PHP: a classic open-source web server setup. phpMyAdmin runs on such a stack; XAMPP (with MariaDB) and MAMP (with MySQL) package one for Windows and macOS. See Lesson 1.2: Installing MySQL.

LEFT JOIN

A join that keeps every row of the left table and fills the right table's columns with NULL where there is no match: every author, including Isaac Asimov, who has no books in the store. See Lesson 4.3: Joins.

LIMIT / OFFSET

Return only part of a result: LIMIT 5 gives the first five rows, LIMIT 5 OFFSET 10 skips ten first. Use them with ORDER BY, or "first" means nothing. See Lesson 3.2: Sorting & Limiting Results.

LOAD DATA INFILE

A statement that bulk-loads rows from a text file (usually CSV) into a table, much faster than single INSERTs. The server reads only from the secure_file_priv folder; LOAD DATA LOCAL reads from the client's machine. See Lesson 8.1: Importing & Exporting Data.

LTS (Long-Term Support)

A release line that receives fixes for years without new features. MySQL 8.4 and 9.7 are LTS releases; this course targets 9.7. Between LTS releases come innovation releases; after 9.7 these use calendar version numbers such as 26.x, which is what brew install mysql or Docker's mysql:latest give you. See Lesson 1.2: Installing MySQL.

M

Many-to-Many (M:N)

A relationship where a row on each side can relate to many rows on the other: a book has several categories, and a category has many books. Implemented with a junction table. See Lesson 4.1: Table Relationships.

MariaDB

A fork of MySQL, compatible for most everyday SQL. XAMPP, many Linux distributions and many shared hosts install it, sometimes under the name "MySQL". Differences that matter in this course: no ONLY_FULL_GROUP_BY by default, sorted GROUP BY, no ->> operator, and a different upsert syntax. See Lesson 1.2: Installing MySQL.

mysqldump

The command-line tool that writes a database (or several) to a .sql file of CREATE and INSERT statements: the standard logical backup. See Lesson 8.1: Importing & Exporting Data.

N

Normalization

Organizing tables so each fact is stored once, which prevents update, insert and delete anomalies. The normal forms 1NF, 2NF and 3NF each build on the previous one. See Lesson 6.3: Database Design & Normalization.

NULL

A marker for "no value" (unknown or not applicable). NULL is not zero, an empty string or false, and nothing equals NULL: test with IS NULL / IS NOT NULL, never = NULL. See Lesson 3.1: WHERE Clauses, Operators & Filtering.

O

One-to-Many (1:N)

The most common relationship: one row in table A relates to many rows in table B (one author, many books). The foreign key goes in the "many" table. See Lesson 4.1: Table Relationships.

One-to-One (1:1)

One row in table A relates to at most one row in table B. Used to split rarely used or sensitive columns into their own table. See Lesson 4.1: Table Relationships.

ONLY_FULL_GROUP_BY

A sql_mode setting, on by default in MySQL, that rejects selected columns that are neither grouped nor aggregated (errors 1055 and 1140). MariaDB leaves it off and returns an arbitrary value instead. See Lesson 3.3: Aggregate Functions & GROUP BY.

ORDER BY

Sorts the result by one or more columns or expressions, ascending (ASC, the default) or descending (DESC). Without it, SQL guarantees no row order. See Lesson 3.2: Sorting & Limiting Results.

ORM (Object-Relational Mapper)

A library that maps tables to objects in a programming language so you can work with rows as objects: SQLAlchemy (Python), Eloquent (PHP), Prisma (JavaScript). See Lesson 8.3: Next Steps & Best Practices.

OVER()

The clause that turns a function into a window function and defines its window: which rows (PARTITION BY), in which order (ORDER BY), and optionally which frame of rows. See Lesson 5.2: Window Functions.

P

Parameterized Query

See Prepared Statement.

PARTITION BY

Inside OVER(), splits rows into groups so the window function restarts for each one, for example the average salary per department, shown on every employee's row. See Lesson 5.2: Window Functions.

phpMyAdmin

A web-based tool for managing MySQL and MariaDB in a browser: browse tables, run SQL, import and export, manage accounts. See Lesson 1.3: MySQL CLI & phpMyAdmin.

Prepared Statement

A statement sent with placeholders (?) and the values sent separately. The values can never change the statement's structure, which prevents SQL injection. Applications should build every query with user input this way. See Lesson 8.3: Next Steps & Best Practices.

Primary Key

The column (or columns) that uniquely identifies each row. Never NULL, never duplicated; every table should have one. See Lesson 2.2: Data Types & Constraints.

Principle of Least Privilege

Give every account and application only the privileges its job needs, on only the data it needs. An application never logs in as root. See Lesson 7.4: User Management & Permissions.

Q

Query

A request sent to the database in SQL. A SELECT reads data; INSERT, UPDATE and DELETE change it. See Lesson 1.1: What Is a Database?.

R

RANK()

A window function that numbers rows by an ordering, giving ties the same number and then skipping (1, 2, 2, 4). rank is a reserved word, so name the column something like rank_num. See Lesson 5.2: Window Functions.

Recursive CTE

A CTE written with WITH RECURSIVE that refers to itself: an anchor member supplies the first rows and a recursive member adds rows based on the previous ones, until it finds none. Used for hierarchies (an org chart) and generated series. Without a stop condition it aborts with error 3636. See Lesson 5.1: CTEs & Recursive Queries.

Referential Integrity

The guarantee that every foreign key value points to a row that exists. Foreign key constraints enforce it (errors 1451 and 1452). See Lesson 4.2: Foreign Keys & Referential Integrity.

Relational Database

A database that stores data in tables (relations) of rows and columns, linked by keys. MySQL, MariaDB, PostgreSQL and SQLite are relational. See Lesson 1.1: What Is a Database?.

REVOKE

Removes privileges (or roles) granted earlier. The opposite of GRANT. See Lesson 7.4: User Management & Permissions.

Role

A named collection of privileges, created with CREATE ROLE. Grant privileges to the role and the role to accounts; change the role once and every account that has it follows. See Lesson 7.4: User Management & Permissions.

ROLLBACK

Ends a transaction and undoes every change made since START TRANSACTION. ROLLBACK TO SAVEPOINT undoes only part of it. See Lesson 7.2: Transactions.

Row

One record in a table, with a value (or NULL) for each column. Also called a record or tuple. See Lesson 1.1: What Is a Database?.

ROW_NUMBER()

A window function that numbers rows 1, 2, 3 in the window's order, with no ties: equal values get different numbers. See Lesson 5.2: Window Functions.

S

Savepoint

A named point inside a transaction. ROLLBACK TO SAVEPOINT name undoes the work after it and keeps the work before it. See Lesson 7.2: Transactions.

Scalar Subquery

A subquery that returns exactly one value (one row, one column), usable wherever a single value is: WHERE price > (SELECT AVG(price) FROM books). If it returns more rows, that is error 1242. See Lesson 3.4: Subqueries & Nested Queries.

Schema

The structure of a database: its tables, columns, types, keys, constraints and indexes. In MySQL, CREATE SCHEMA and CREATE DATABASE are synonyms. See Lesson 2.1: Creating Databases & Tables.

secure_file_priv

A server setting that limits which folder SELECT ... INTO OUTFILE and LOAD DATA INFILE may use (/var/lib/mysql-files/ on Linux packages). Other paths fail with error 1290. See Lesson 8.1: Importing & Exporting Data.

Self-Join

A join of a table with itself under two aliases, such as matching each employee to their manager through employees.manager_id. See Lesson 4.3: Joins.

SQL Injection

An attack where user input is pasted into SQL text and changes what the statement does. Prevented with prepared statements (parameterized queries), never by building SQL strings from input. See Lesson 8.3: Next Steps & Best Practices.

sql_mode

The server setting that controls how strictly MySQL checks SQL and data. The default includes STRICT_TRANS_TABLES (reject bad values instead of adjusting them) and ONLY_FULL_GROUP_BY. Leave it at the default. See Lesson 3.3: Aggregate Functions & GROUP BY.

SQL (Structured Query Language)

The standard language for defining, querying and changing relational data. Every relational database speaks it, with small dialect differences. See Lesson 1.1: What Is a Database?.

Stored Function

A routine that returns one value and can be used inside queries, like a built-in function: SELECT discount_price(price, 20) FROM books. It must be declared DETERMINISTIC, NO SQL or READS SQL DATA (error 1418). See Lesson 7.1: Stored Procedures & Functions.

Stored Procedure

A named block of SQL stored in the database and run with CALL. It can take IN, OUT and INOUT parameters and contain logic and several statements. See Lesson 7.1: Stored Procedures & Functions.

Subquery

A query nested inside another, in WHERE, FROM or SELECT. It can return a single value, a list or a table. See Lesson 3.4: Subqueries & Nested Queries.

T

Table

The basic storage unit of a relational database: rows of data in named, typed columns. Also called a relation. See Lesson 1.1: What Is a Database?.

TCL (Transaction Control Language)

The statements that manage transactions: START TRANSACTION, COMMIT, ROLLBACK, SAVEPOINT. See Lesson 7.2: Transactions.

Transaction

A group of statements that succeed or fail as one unit: START TRANSACTION, the changes, then COMMIT (keep all) or ROLLBACK (undo all). See Lesson 7.2: Transactions.

U

UNIQUE

A constraint (and index) that forbids two rows from having the same value in a column or combination of columns. A violation is error 1062. See Lesson 2.2: Data Types & Constraints.

Upsert

Insert a row, or update it if its key already exists: INSERT ... ON DUPLICATE KEY UPDATE. MySQL's current form uses a row alias (VALUES (...) AS new ... col = new.col); MariaDB uses VALUES(col). See Lesson 2.3: CRUD Operations.

utf8mb4

MySQL's complete UTF-8 encoding, up to 4 bytes per character, so it stores every language and emoji. Always choose it; MySQL's old utf8 (utf8mb3) stops at 3 bytes and is deprecated. See Lesson 2.1: Creating Databases & Tables.

V

View

A saved SELECT that you query like a table. It stores no data of its own; it simplifies complex queries and can limit what users see. See Lesson 6.2: Views.

W

WHERE

The clause that keeps only the rows matching a condition, in SELECT, UPDATE and DELETE. It runs before GROUP BY and HAVING. See Lesson 3.1: WHERE Clauses, Operators & Filtering.

Wildcard

A pattern character in LIKE: % matches any number of characters (including none) and _ exactly one. See Lesson 3.1: WHERE Clauses, Operators & Filtering.

Window Function

A function computed over a set of rows related to the current row, written with OVER(), without collapsing the rows the way GROUP BY does: rankings, running totals, moving averages, previous and next values. It cannot be used in WHERE (error 3593). See Lesson 5.2: Window Functions.
